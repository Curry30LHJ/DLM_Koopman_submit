Reviewer 1, Comment 2

In practical chemical processes, it is quite common to encounter multiple time delays associated with variables measured or sampled at different frequencies. Could the authors elaborate on how the proposed framework could accommodate such situations? Even if a numerical demonstration is beyond the scope of the current work, a conceptual discussion would be valuable for understanding its applicability to realistic chemical processes.

Thank you for this suggestion. We have added a conceptual discussion that distinguishes multiple physical delays from asynchronous acquisition and delayed measurement availability. It also separates the current implementation from the data-interface and model extensions that would be required. The additions appear in Sections 2.1, 3.1, and 4.4.

For several fixed physical delays, the synchronized joint history can in principle contain multiple lagged dependencies. DLM-K does not receive a single physical-delay scalar that would algebraically limit it to one lag. If known delays satisfy tau_j = q_j Delta t with integer q_j, retaining the corresponding sampled coordinates requires L_h - 1 >= max_j q_j. This is a window-coverage condition, not a sufficient-history or prediction guarantee. The same algebraic encoder and rollout form could be identified from representative multiple-delay trajectories with a suitable history and capacity. Known lagged coordinates could also be appended to a lift or dictionary, with changed feature specification and refitting; noninteger lags would require physical-time queries from causally available data rather than silent rounding. The current plant examples have one distinct delay each, and the previous three-delay experiment fits separate single-delay conditions. Neither is a simultaneous multiple-delay experiment.

Our source audit confirms that the released window builder slices consecutive array indices. The LSTM consumes synchronized state-input values, HaKAN patches use sequence positions, and AFT uses index-based positional biases. No acquisition timestamps, observation masks, measurement ages, or varying transition intervals are supplied to these modules. The AFT causal mask excludes future latent tokens and does not handle missing sensor channels. The Lorenz solver uses timestamps for internal delayed-state interpolation, but this does not give the learned model an asynchronous observation interface. Two frozen-checkpoint synthetic API probes further confirmed that attaching and changing extra timestamp, mask, age, and forecast-interval fields while retaining the numerical model inputs leaves predictions identical. This is an interface check, not a multirate process-performance result; it shows that merely attaching metadata to the existing input dictionary does not implement the proposed extension.

One extension is to map channel timestamps to a common clock and adopt a fixed forecast grid. Acquisition time and arrival time should both be recorded. A conservative causal policy uses only measurements acquired and available by each grid time, carries eligible values forward when appropriate, and retains per-channel indicators for new, held, and missing observations plus the acquisition age. Known actuator hold intervals would be aligned to that grid. Later observations must not enter an earlier forecast, and upsampling a slow channel does not create new physical information. Observation-mask and elapsed-time representations are supported by the multivariate missing-data literature (Che et al., 2018), but they are not currently implemented in our encoder. Adding them requires modified input dimensions, preprocessing, and training under the same alignment and missingness policy used at deployment. The latent transition must be fitted for the selected forecast interval.

Asynchrony also changes the interpretation of the current-state path. Held sensor values are not necessarily the simultaneous physical state copied into the present lift prefix and used for current-state conditioning. An extension must therefore supply a causal current-state estimate or redesign the observation-based lift, readout, and prediction target. If training targets are missing, a defined observation model or masked loss is needed; validation of full-state accuracy still requires suitable reference states. Increasing latent memory M cannot supply the measurements absent from the initial history.

A second route is a timestamp-aware event or channel encoder that summarizes irregular observations before forecasting on a uniform output grid. The latent buffer can then remain indexed by uniform forecast steps, while the new initialization is jointly trained with the predictor. If the forecast itself uses irregular event intervals, propagation and context timing must also depend on elapsed time; the present fixed-step A, B, and AFT positional bias cannot simply be reused as variable-step operators. These routes require new interfaces, fitting, and independent validation. We have not presented their accuracy as an established result.
