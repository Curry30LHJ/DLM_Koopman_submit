R2-5 参数量核验与修改说明

审稿人原文：How many parameters do you optimize?
问题含义：需要交代实际学习哪些参数、总量多少，以及分阶段训练时究竟有哪些参数进入优化器。

核验结果（Lorenz / CSTR；主实验 Lh=M=20）：
完整 DLM-K：160,110 / 162,747。
阶段 A 初始化：155,929 / 157,180。
阶段 B AFT 单独优化：4,181 / 5,567，其他模块冻结。
阶段 C 联合微调：160,110 / 162,747，复用前两组参数，不能把三个阶段加起来。

模块明细（Lorenz / CSTR）：
LSTM：1,344 / 1,920；当前状态映射：48 / 144。
共享 patch 投影：192 / 192；patch 位置嵌入：256 / 256。
块内 Hahn 系数：20,480 / 20,480；块间 Hahn 系数：1,280 / 1,280。
可观测量投影：131,104 / 131,104；线性 A：1,225 / 1,681；输入 B：0 / 123。
AFT Q/K/V：3,780 / 5,166；AFT 位置偏置：400 / 400；门控：1 / 1。
固定读出 C：0 个学习参数。最大的一项是展平后的可观测量投影。

计数口径：按优化器登记的参数张量标量元素计数，包含权重和偏置，并非每一步非零梯度数量，也不是可辨识的独立自由度。AFT 的400个位置元素中190个上三角元素被屏蔽，1个单元素上下文位置不使用，209个参与长度2–20的上下文。键投影偏置的公共平移会在softmax中抵消。零门控初始时分支权重梯度为零，门控可先接收梯度。保留原结构和权重，没有为了修改数字而改变模型。

证据：8个神经模型与4个RBF存档文件的哈希核验；严格加载原神经模型；逐参数枚举与独立尺寸公式核对；实际优化器分组及原始Adam状态核对；原阶段学习率日志核对；原AFT训练前后非AFT权重逐元素一致；最终稿件模型与原最终联合阶段检查点完全相等。合成双精度反向传播仅用于检查梯度路径，未执行优化器更新或重训。全部原文件哈希保持不变。
