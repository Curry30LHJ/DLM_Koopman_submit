Reviewer 1, Comment 1

I would be interested to know how the proposed framework could be extended to larger-scale systems with many interacting states and inputs. It would be helpful if the authors could discuss potential computational challenges and limitations when applying the method to more complex systems.

Response:

Thank you for this suggestion. We have expanded Section 4.3 and added a computational-scaling discussion in Appendix B. The revised text explains how the state and input dimensions, observed history, latent context, representation widths, and prediction horizon affect the present implementation, and identifies specific implementation and architectural directions for larger interacting systems.

The formulation can accept larger state and input vectors, but its recurrent dimension is n_z = n_x + d_psi because the physical state is retained explicitly. Consequently, fixing the number of learned observables does not fix the recurrent dimension. The dense transition and three AFT projections have quadratic dependence on n_z, while the input map contains n_u n_z entries. Including affine AFT biases, positional biases and the gate, the recurrent part has exactly P_rec = 4 n_z^2 + (n_u + 3)n_z + M^2 + 1 learned scalars. This count excludes the initialization encoder and lift, whose module counts are given in Table B.2. We verified the formula against instantiated models at ten dimension configurations, including both reported benchmarks; this is a dimension audit, not an additional large-system prediction experiment.

The initialization encoder is evaluated once per forecast origin. Its one-layer LSTM cost grows as O(b(L_h - 1)d_h(n_x + n_u + d_h)); the patch embedding, Hahn mixing and final observable projection add the terms stated in Appendix B. A longer history increases the patch count and, in particular, the quadratic inter-patch mixing term and the size of the flattened projection. Keeping all widths fixed can limit representation of more complex interactions, while increasing hidden and observable widths adds computation and parameters. Thus, scaling cannot be assessed by changing the number of physical states alone.

The current AFT implementation projects the full active context of length m and materializes all query rows before returning the last row. Its weighting tensors contain b m^2 n_z elements. Including the dense transition, an H-step forecast has the upper-bound arithmetic cost O(bH[(M + 1)n_z^2 + n_u n_z + M^2 n_z]), in addition to initialization. The actual context is min(s + 1, M), with AFT bypassed for the singleton context. Training retains intermediate activations for differentiation through the rollout, and the Lorenz configuration additionally evaluates a spectral regularizer. The revised discussion connects these dependencies to the measured storage results in Table B.6, while distinguishing operation counts from measured runtime and memory.

We identify an implementation improvement that preserves the recurrence: evaluate only the final AFT query row using all admissible keys and values. This reduces the weighting work and temporary tensor size from O(b m^2 n_z) to O(b m n_z), while retaining O(b m n_z^2) projection work and the learned M-by-M positional-bias array. A disposable float64 check at nine context/dimension settings, with a nonzero gate and nonuniform positional biases, matched the original AFT outputs and input/parameter gradients to within 2.8 × 10^-17. This verifies the algebraic implementation direction; the manuscript's experiments and storage measurements still use the original code, and we report no measured speedup or memory reduction from this change. A rolling latent buffer and omission of inference diagnostics are further implementation options.

For plants with known unit connectivity, the revised discussion also proposes local history encoders combined with sparse or block-structured transition and input maps that preserve inter-unit couplings. This would be an architectural modification requiring retraining and validation, with a tradeoff between representational capacity and cost. The current three-state Lorenz and nine-state CSTR examples do not establish large-plant accuracy or data requirements. Evaluation at that scale requires representative excitation, coverage of coupled operating regimes, and resource measurements at the intended dimensions. These additions appear in Section 4.3 (PDF viewer page 18, printed page 17) and Appendix B (viewer pages 24–25, printed pages 23–24). All additions are blue. The previous five revision rounds, numerical results, figures, tables, equation numbering and bibliography are preserved.
